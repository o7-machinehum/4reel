Fisheye stereo calibration

Checking fisheye calibration…

Focus both lenses first. Capture a stationary checkerboard in varied positions across the shared view, then solve the calibration on your computer using the supplied calibration tool.

Download native stereo pair

Native calibration capture pauses depth processing. Calibrated output covers the common rectified view. The camera clocks are independent, so keep the target still for each pair.

Camera controls

Automatic exposure adjusts both cameras together. With ZipDepth enabled, it meters the left perspective input and the right stereo view and allows small bright reflections to clip. Focus meters the selected camera. Exposure and gain are sensor control values, not milliseconds or dB.

Calibrate depth

  1. Start capture. Put a high-contrast, stationary target at a measured near distance from the camera pair; take a near snapshot.
  2. Click the same physical feature in the left and right snapshot images. You can fine-tune the pixel coordinates below each image.
  3. Move that target to a measured far distance and repeat. Enter both distances in millimetres, then select Calibrate.

Use a static scene: the two sensors have independent clocks. Two distances give an approximate depth scale and offset; this does not correct lens distortion, rotation, or full camera intrinsics. For accurate metric depth, use a full stereo calibration.

Take both snapshots, select the same feature in each camera, and enter the two distances.

Full-resolution lens focus

Download full-resolution frame

Native 1280 × 800, one camera at a time. Turn the lens gently to focus; these lenses have no motorized autofocus.

Depth matching pauses while focusing. Full-resolution BMP frames are about 1 MB, so updates are slower over 12 Mbps USB. Auto-exposure/gain controls are on .

Place a high-contrast target near the centre and use 1:1 pixels to inspect detail. Auto exposure adjusts on each focus frame; disable it in Calibration to hold brightness steady while turning the lens.

Select a camera and start focus capture. Switching tabs does not change capture mode.

Finish focusing both lenses before calibration. If you change focus after calibration, recalibrate.
