Automatic exposure optimizes both cameras together for depth matching. Exposure and gain remain visible as sensor control values, not milliseconds or dB.

Calibrate depth

  1. Start capture. Put a high-contrast, stationary target at a measured near distance from the camera pair; take a near snapshot.
  2. Click the same physical feature in the left and right snapshot images. You can fine-tune the pixel coordinates below each image.
  3. Move that target to a measured far distance and repeat. Enter both distances in millimetres, then select Calibrate.

Use a static scene: the two sensors have independent clocks. Two distances give an approximate depth scale and offset; this does not correct lens distortion, rotation, or full camera intrinsics. For accurate metric depth, use a full stereo calibration.

Take both snapshots, select the same feature in each camera, and enter the two distances.
